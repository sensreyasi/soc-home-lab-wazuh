# Security and Responsible Use

This repository is intended for **authorised, isolated cybersecurity education**.

- Use only endpoints and accounts you own or are explicitly authorised to test.
- Do not expose Wazuh dashboard or management ports to the public internet.
- Never commit credentials, API keys, private certificates, personal data, or raw logs.
- Redact usernames, IP addresses, hostnames, and identifying details in screenshots.
- Treat the configuration example as illustrative; verify against the installed Wazuh release.
- All test outcomes remain unverified until documented with actual evidence.

For a suspected credential leak, revoke the credential and remove it from Git history before continuing.
